\# File Analyzer



A beginner-friendly Python project that reads a text file and performs basic text analysis.



\## Features



\- Reads a text file

\- Counts lines

\- Counts words

\- Counts characters

\- Searches for words

\- Calculates average words per line

\- Displays a final report

\- Handles file errors



\## Technologies Used



\- Python



\## Python Concepts Learned



\- File Handling

\- open()

\- with open()

\- split()

\- splitlines()

\- count()

\- len()

\- lower()

\- round()

\- try-except

\- Variables

\- Data Analysis
